## 📚 Índice Modular de Lecciones

- [01 - Arquitectura de Von Neumann y Elementos Funcionales del Procesador](./01_arquitectura_von_neumann_y_procesamiento.md)
  - Modelo Von Neumann, CPU (UC, ALU, registros PC/IR/MAR/MDR), ciclo de instrucción Fetch-Execute y buses del sistema.
- [02 - Componentes Físicos: Placa Base, Memoria RAM y Almacenamiento Secundario](./02_componentes_fisicos_placa_memoria_almacenamiento.md)

- [03 - Ensamblado, Diagnosis y Mantenimiento de Equipos Microinformáticos](./03_ensamblado_diagnosis_y_mantenimiento.md)

- [04 - Respaldo, Recuperación y Creación de Imágenes de Sistema](./04_respaldo_recuperacion_y_creacion_imagenes.md)
  - Estrategia 3-2-1, copias completas/diferenciales/incrementales, niveles RAID (0, 1, 5, 10), RTO/RPO y clonación con `dd`/`rsync`.
- [05 - Centros de Procesamiento de Datos (CPD), Estándares TIA-942 y Cloud Computing](./05_centros_de_procesamiento_de_datos_y_cloud.md)
  - Niveles TIER I a IV, métrica PUE, pasillos fríos/calientes, SAIs y modelos de nube (IaaS, PaaS, SaaS).
