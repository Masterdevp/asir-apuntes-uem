## 📚 Índice Modular de Lecciones

- [01 - Arquitectura y Fundamentos de los Sistemas Operativos](./01_arquitectura_y_fundamentos_sistemas_operativos.md)
  - Funciones de un SO, núcleo (kernel monolítico vs microkernel vs híbrido), modos de ejecución Ring 0/Ring 3 y llamadas al sistema (syscalls).
- [02 - Gestión de Procesos, Hilos de Ejecución y Planificación de CPU](./02_gestion_de_procesos_hilos_y_planificacion.md)
  - Estructura PCB, ciclo de vida de procesos, cambio de contexto, planificador CFS, señales del kernel (SIGTERM, SIGKILL, SIGHUP) y monitorización CLI.
- [03 - Gestión de Memoria Virtual y Sistemas de Archivos](./03_gestion_de_memoria_y_sistemas_de_archivos.md)
  - Paginación, MMU, TLB, Swap, hiperpaginación (*thrashing*), inodos en sistemas de archivos Linux (EXT4) y enlaces duros vs simbólicos.
- [04 - Administración de Usuarios, Permisos POSIX, ACLs y Servicios con Systemd](./04_administracion_de_usuarios_permisos_y_servicios.md)
  - Matriz de permisos (rwx), permisos especiales SUID/SGID/Sticky bit, listas de control de acceso (ACLs) y gestión de servicios y unidades con `systemd`.
