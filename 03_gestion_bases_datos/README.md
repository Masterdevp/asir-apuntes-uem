## 📚 Índice Modular de Lecciones

- [01 - Introducción a los Sistemas Gestores de Bases de Datos (SGBD)](./01_introduccion_sistemas_gestion_bases_datos.md)

- [04 - Lenguaje SQL: Definición (DDL), Manipulación (DML), Consultas (DQL) y Transacciones (TCL)](./04_lenguaje_sql_ddl_dml_dql_tcl.md)

- [05 - Bases de Datos en la Nube y Modelos NoSQL](./05_bases_datos_cloud_y_nosql.md)
